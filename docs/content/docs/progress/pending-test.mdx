# 待测试

- v3.142.0 时长 Hook 硬路由：用单条参考图连线分别生成 10 秒 Omni 和 15 秒 MiniMax H3 带货视频；10 秒必须在前 2 秒出现可见反直觉事件，15 秒必须在前 3 秒出现，普通手持、正常走路、慢推镜、静态商品特写或标准演示均判定不合格。Hook 后立即进入卖点，末 2 秒或 3 秒只保留商品主视觉与一个 CTA，剧情不得有空拍和重复镜头。

- v3.142.0 地域按需路由：输入“生成一段印尼带货视频”时应使用适配印度尼西亚社交电商的场景和自然 Bahasa Indonesia；输入未指定地域的“生成一段带货视频”时保持全球中性，不得默认任何国家、城市、语言、货币或平台。

- v3.140.0 全球地域路由：从提示词中心打开“全球商业强 Hook 导演”，未写国家或城市时，输出不得预设印尼、美国、固定语言、货币、地标或平台徽标；分别补充“墨尔本 Instagram Reels、澳元”和“印度尼西亚 TikTok Shop、Bahasa Indonesia”后，只使用对应市场元素且不得混入其他地域。

- v3.140.0 强 Hook 路由：用“帮我生成一条带货视频”验证会比较至少 3 种不同 Hook 并按停滑力、商品清晰度、可执行性、安全性和地域适配择优；连续使用不同商品时不得都套同一事故。允许超现实坠落时必须无伤害、无血腥、不可模仿，商品不得成为危险动作的原因或工具；明确“不要人物”时只使用纯商品/环境 Hook。

- v3.140.0 长提示词兼容：提交超过 600 字或带完整时间轴的商业视频提示词，确认仍逐项保留用户地域、镜头、台词和所有禁令，不得被强 Hook 模板改写；中等提示词只轻量补全现有 Hook。

- v3.139.0 长提示词路由：连接海报和商品多视图两张参考图，提交含 0–10 秒完整时间轴以及“不要人物、不要烟雾、仅正面、不旋转”的长提示词；任务日志中必须保留提示词最后的 WhatsApp 禁令，且不得注入主播、人物反应或口型模板。

- v3.139.0 短提示词补全：用“生成一个带货广告”验证原完整带货结构仍会补全；用“不要人物，只展示商品并上下跳动”验证自动改用纯商品结构，不得出现主播、手、口型或人物反应。
