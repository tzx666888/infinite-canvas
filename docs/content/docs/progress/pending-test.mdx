# 待测试

- v3.0.104 分销计费：Root 设置分销管理员后，管理员应可创建多个售价方案并绑定自己的邀请码；新客户通过该邀请注册后，核对同步生成按售价扣费并立即结算差价，异步视频在提交时不返佣、最终成功后才返佣，失败时客户全额退分且管理员无收益。重复查询同一视频任务不得重复返佣；停用方案后不得用它注册新客户。

- v3.0.103 画布稳定性：在包含多张图片、视频和音频节点的画布中缩放、拖动画布并刷新页面，确认远处媒体只显示轻量占位、放大或选中后才加载预览；点击生成视频后立即刷新或短暂断网再恢复，确认节点继续显示生成中并在任务完成后自动恢复视频，不重复扣费、不重复提交。重点复现此前反复出现的 “This page couldn’t load” 页面错误。

- v3.0.102 认证与账务边界：旧中转站账号/密码不得再通过画布登录迁移桥进入画布；画布本地账号、邀请码注册、注册后自动创建的“平台默认 Key”、账户页手动创建的画布 Key、模型网关、图片任务、视频任务、Agent、画布积分/订单/流水和回滚流程仍应正常。确认画布服务不再请求中转站 `/api/internal/canvas/auth`，不读取或导入中转站余额，但 `/api/gateway` 与 `/api/tokaxis` 的画布到模型服务链路保持可用。
- v3.0.100 印尼 TikTok H3 爆款导演：需用真实商品参考图验证 Product Truth Sheet 会提取品类、SKU、卖点、包装外观与逐字包装文字；模糊文字、多 SKU、语言变体不明或证据不足时先提问且不编造。确认后验证 0–3 秒 Hook、3–10 秒证据、10–15 秒转化、Bahasa 口播/字幕分栏、可复制 H3 英文 prompt，以及生成后六项质检和定向重跑建议。
- 画布视频生成前确认：需分别从普通视频节点、视频 Config 节点和 12 宫格“生成整片”打开必填信息弹窗；验证提示词、模型、时长、画幅、清晰度及已连接图片/视频/音频摘要正确回填。Omni 应固定 10 秒/720p，Veo 与 Seedance 应按各自路由限制实时切换；不支持的参考类型、超限数量和空输入必须阻止确认。还需确认取消不清空视频草稿、不创建计费任务，确认后参数保存到节点且只提交一次。
- 待发布 Agent 视频逐题选择与质量修复：在生产画布选中一张产品图后，在线与本地 Agent 都应每次只显示一个可点击问题，不要求客户输入文字；首项必须明确显示“达人出镜（选参考模特）”，点击后出现“选择参考模特”及画布人物缩略图，每张卡清楚标示“用作参考模特”；“纯产品展示”必须明确不出现人物。完成一轮后，再输入“生成一个带货视频”必须自动重新从视频类型选择开始，不能复用旧会话的市场、模型和时长。依次覆盖视频类型、达人/证言人物缩略图、市场、平台、语言、横竖屏、当前可用模型、有效时长、声音、字幕和卖点；人物加产品不得出现首尾帧语义模型。Omni 固定时长只显示一个选项，无声模型或关闭声音后不得提供字幕；新增模型完成中央能力登记后应自动进入兼容的选择器。全部选完后只调用一次 Agent，提示词正文应为 45–85 个英文词，最终单次编译结果为 90–170 个英文词、单场景且最多三个可见节拍，不得二次包装；开启声音时必须包含一条 `Spoken script: "..."` 当地语言口播，字幕开启时逐字复用。客户确认后只创建一个 `idle` 普通视频节点并连接参考图，不自动提交或扣费；达人模式连接顺序必须为人物→产品。节点生成时的模型、时长、画幅和声音必须与引导选择完全一致，不能回退到全局默认模型；改参数需重新运行引导。还需核对公开的视频工作台、分镜、普通连线与历史视频节点不受影响。
- v3.0.77 邀请注册统一身份：需在生产画布用一次性邀请码注册新账号，确认同一用户名立即出现在中转站用户管理、邀请码只增加一次使用次数且新账号可用同一密码重新登录画布；另需用一个 v3.0.73-v3.0.76 期间创建的旧本地账号登录一次，确认自动补建中转站账号并迁移为统一身份。同名冲突与中转站服务不可用时不得消耗邀请码。本版不得改变图片、视频、提示词、模型、价格或生成参数。
- v3.0.72 H3 参考素材桥接：需在生产画布用浏览器本地图片生成 `MiniMax-H3-c4` 视频，确认创建接口可在短时间内返回任务 ID、中转站任务日志立即出现记录、任务成功后能播放和下载；临时素材 URL 不得包含 API Key，并应在 24 小时后失效。本版不得改变模型 ID、5–15 秒、1440p、横竖屏、声音或参考素材数量参数。
- v3.0.66 真人视频审核提示：需在生产画布的达人模式选择 QY Seedance，确认界面会提示可识别真人图受上游隐私审核；当上游返回 `reference_image_unsafe_error`、隐私检查或肖像保护失败时，节点和视频卡应显示“参考人物图未通过隐私审核”、自动退回额度说明和 Omni / Veo 重试入口，不得显示原始上游错误或“参考素材丢失”。
