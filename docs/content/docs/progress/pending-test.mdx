# 待测试

- v3.0.78 Agent 视频引导：在生产画布选中一张产品图后，在线与本地 Agent 都应直接用文字询问视频类型，不再显示视频参数卡；逐步完成市场、平台、语言、人物参考、横竖屏、模型、有效时长、声音、字幕和卖点后，必须先展示中文摘要及完整英文提示词并等待明确确认。确认后只创建一个 `idle` 普通视频节点并连接参考图，不得自动提交或扣费；达人模式连接顺序必须为人物→产品，人物与产品不能是同一节点。模型选项、固定/范围时长、清晰度、声音与参考图上限必须来自当前中央能力表，未登记能力的模型不得猜测或静默换模。还需核对公开的视频工作台、分镜与历史视频节点不受影响。
- v3.0.77 邀请注册统一身份：需在生产画布用一次性邀请码注册新账号，确认同一用户名立即出现在中转站用户管理、邀请码只增加一次使用次数且新账号可用同一密码重新登录画布；另需用一个 v3.0.73-v3.0.76 期间创建的旧本地账号登录一次，确认自动补建中转站账号并迁移为统一身份。同名冲突与中转站服务不可用时不得消耗邀请码。本版不得改变图片、视频、提示词、模型、价格或生成参数。
- v3.0.72 H3 参考素材桥接：需在生产画布用浏览器本地图片生成 `MiniMax-H3-c4` 视频，确认创建接口可在短时间内返回任务 ID、中转站任务日志立即出现记录、任务成功后能播放和下载；临时素材 URL 不得包含 API Key，并应在 24 小时后失效。本版不得改变模型 ID、5–15 秒、1440p、横竖屏、声音或参考素材数量参数。
- v3.0.66 真人视频审核提示：需在生产画布的达人模式选择 QY Seedance，确认界面会提示可识别真人图受上游隐私审核；当上游返回 `reference_image_unsafe_error`、隐私检查或肖像保护失败时，节点和视频卡应显示“参考人物图未通过隐私审核”、自动退回额度说明和 Omni / Veo 重试入口，不得显示原始上游错误或“参考素材丢失”。
- v3.0.59 生成错误与视频能力：需在生产画布分别验证内容审核、余额不足、模型资源不足、超时和参考素材上传失败均只显示客户可理解的中文原因，不展示服务名、项目 ID 或上传路径；同时验证 Veo 多参考固定为 8 秒 720p，三款 Seedance 只可选择 5/10/15 秒，超过 12MB 的参考图在提交前给出明确提示。
- v3.0.58 画布 Agent 带货视频 M3+M4：需人工核对 P0 市场顺序、P1/P2 灰色待开放项、中国卡片的抖音 / 快手语境，以及字幕开关默认关闭、开关规则互斥、提示词锁定区、参数变更失效和编辑后零二次编译；需比对中文字幕关 / 开 Omni 真实成片与联系表，并核对横屏请求和成片确为 `omni` / `1280x720`。四份派生语料仍待鑫哥复核。
- v3.0.57 画布 Agent 带货视频卡片：需在生产画布核对默认纯手部 / 菲律宾 / Omni 竖屏、达人第二参考图、Seedance 无声标记以及视频节点生成；Seedance 成片待渠道修复后验。
- Tokaxis 可视化提示词库：需验证提示词中心只显示“Tokaxis 创作 / 商品电商 / 商业人物”三类，不再出现游戏、纯 UI、纯建筑和信息图模块；Agent 选择工作流后只填入启动指令、不自动发送，图片入口只显示图片模板，视频入口只显示经统一视频管线适配的 Tokaxis 视频提示词。
- v3.0.28 提示词编辑埋点：需分别验证 Agent 生成后人工改写、`user_typed` 改写与上游引用节点删除三种路径；前两者的 `prompt_edited.beforeText` 必须与上一条 `generation.promptText` 完全一致，缺失引用时必须不上报 `prompt_edited`，新增 JSONL 不得出现 `@[node:` 占位符。
- v3.0.27 画布行为埋点：需在全新浏览器依次完成 Agent 对话、图片生成、人工改写后再生成、60 秒内删除，并在宿主机 `/opt/infinite-canvas-data/telemetry/events-YYYYMMDD.jsonl` 核对完整事件链；同时验证文件内不含图片数据、Base64 或图片 URL，端点断开不影响生成且控制台无埋点错误，`TELEMETRY_ENABLED=0` 不落盘，容器重建后历史 JSONL 仍保留。可用 `node scripts/telemetry-report.mjs /opt/infinite-canvas-data/telemetry` 输出只读汇总。
- v3.0.26 图片批量：需验证顶部导航与移动端入口、多图选择及拖拽、刷新恢复、1–5 路并发、不限或 60–600 秒单张超时、停止全部、失败项/单项重试、单张与 ZIP 下载、移除/清空，以及通过分类菜单保存到“我的素材”；还需分别用 OpenAI、Gemini 和 Google 图片模型核对每张原图均作为独立参考图请求。
- 我的素材：分类筛选已在素材页直接展开，内置场景、人物、男模、女模、商品、服装、道具、动作姿势、镜头构图、风格参考、品牌素材、提示词和其他，并支持自定义分类；画布、生图工作台、视频创作台和提示词库保存素材时会先弹出分类菜单。需验证分类选择与取消保存、新增、编辑、搜索、筛选、画布选择器、旧素材补默认分类及导入导出。
- v3.0.25 电商分镜视频：独立关键帧按 Beat 使用 12 宫格的对应单格锁定构图、人物服装和动作，原始素材只锁定人物/商品身份；整片视频直送已批准关键帧，禁止未规划的换装、桌子、额外衣物、商品提前出现和口播改写；需用含真人、服装和商品的完整分镜核对首帧、中段动作、人物/商品一致性、口播自然度和可见口型。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。

- Google 4K 生图：画布只公开 `gemini-3.1-flash-image-4k`，旧无后缀、1K、2K 配置和历史节点会在提交前自动迁移为 4K；需验证模型同步和分辨率面板只显示 4K，并用 1:1 真实生成结果核对原图为 4096×4096，同时确认 14 种官方比例仍可选。
